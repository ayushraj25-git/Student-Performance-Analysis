# Student Performance Analysis

A Python-based project to analyze student marks, calculate grades, identify toppers, and visualize student performance.

## Features

- Calculate average, highest, and lowest marks
- Identify the topper
- Sort students by marks
- Assign grades based on marks
- Calculate Pass/Fail results
- Update and search student records
- Calculate student rankings and percentages
- Generate marks and Pass/Fail charts
- Save and read results using CSV files

## Technologies Used

- Python
- Pandas
- Matplotlib
- CSV

## Project Files

- `main.py` — Main Python program
- `students.csv` — Student records
- `student_results.csv` — Analyzed student results
- `student_marks.png` — Student marks chart
- `pass_fail_chart.png` — Pass/Fail pie chart

## How to Run

1. Install Python.
2. Install the required libraries:

   ```bash
   pip install pandas matplotlib
   ```

3. Run the program:

   ```bash
   python main.py
   ```

4. Follow the terminal prompts to update marks and search for students.

## Learning Outcomes

This project demonstrates basic data analysis, data filtering, sorting, CSV file handling, functions, and data visualization using Python.
